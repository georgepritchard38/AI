## Heuristic Functions

This project uses a heuristic function to create an AI agent that plays the game of Teeko. The agent calculates a heuristic based on the pieces' relative distance to eachother and their winning orientations for both the red and black pieces. Using a minimax function, the agent calculates the best move based on the heuristic and a depth of successor states that can be adjusted. The file sample_game.txt displays an example game between me and the agent. The agent keeps beating me and I have mixed feelings about that.
