## Convolutional Neural Networks

This project contains three parts. The first part builds, trains and evaluates the LeNet-5 convolutional neural network on the CIFAR100 dataset of 60,000 images with 100 classes. The is the major portion of the project. The model contains two convolutional layers, one flattening layer, and three linear layers, amounting to 151,324 learnable parameters in total. The file "results.txt" contains the accuracy of the model with the following seven different hyperparameter configurations (in order of appearance):

1) epochs: 10, learning rate: 0.001, batch size: 32
2) epochs: 10, learning rate: 0.001, batch size: 8
3) epochs: 10, learning rate: 0.001, batch size: 16
4) epochs: 10, learning rate: 0.05, batch size: 32
5) epochs: 10, learning rate: 0.01, batch size: 32
6) epochs: 20, learning rate: 0.001, batch size: 32
7) epochs: 5, learning rate: 0.001, batch size: 32

The second part of the project trains nanoGPT on Shakespeare's written works and generates text based off of them. The file "generated_nanogpt.txt" contains some example text generated by this model.

The final part of the project trains DistilGPT2 on a small text dataset, and generates text-based responses to written prompts based on its training text. The file "generated_distilgpt.txt" contain some example responses generated by the model, as well as the text prompts.
